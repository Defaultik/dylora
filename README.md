## 📖 What is this?

`dylora` is a Windows utility that lets you inject `.dll` files into running processes.  
Pick a target by Process Name or PID, provide a DLL path, and it handles the rest.

---

## ✨ Features

| Feature | Details |
|--------|---------|
| 🗣️ **Unicode Support** | Process names render correctly in any language — Russian, Chinese, Arabic, and more |
| 🔍 **Flexible Targeting** | Select a process by name (e.g. `notepad.exe`) or by PID |
| 🎨 **Colored Output** | Green on success, red on failure |

---

## 🚀 Usage

> [!IMPORTANT]  
> Run as **Administrator** — opening a process handle with the required access rights needs elevated privileges.

1. Launch `dylora.exe`
2. A list of all running processes is printed with their PIDs
3. Enter a **process name** (e.g. `notepad.exe`) or a **PID** (e.g. `1234`)
4. Enter the path to the `.dll` you want to inject (absolute or relative)
5. Done — the result is printed in green or red
